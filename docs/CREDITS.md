# Credits

## Music

The game plays eight public-domain classical pieces, rendered offline through the original game's own synthesiser (`sounds/music/*.ogg`). The compositions are in the
public domain. The MIDI files were taken from the [Mutopia Project](https://ibiblio.org/mutopia/legal.html), which
lists each of these as **Public Domain**. The note data came from those MIDI files.
